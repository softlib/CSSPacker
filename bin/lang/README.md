# 扩展 GUI 界面语言

本目录中的 `*.ini` 文件会在 CssPackerGui.exe 启动时自动加载，用于**新增语言**或**覆盖内置语言的个别文本**。

## 文件格式

```ini
[Lang]
Name=Italiano          ; 下拉框中显示的语言名称
Code=it                ; 语言代码（可省略，默认取文件名）

[Strings]
btn.open=Apri...
btn.save=Salva...
```

- `[Strings]` 中只需列出想修改的键，未列出的键自动回退到英文。
- 文本必须使用 UTF-8 编码（建议带 BOM）。
- 带 `%s` 的条目是格式化模板，请保留占位符数量与顺序。

完整的字符串键列表见 `Lib/CssPacker.Lang.pas` 顶部的 `TXT_*` 常量。

## 示例

`it.ini` 是一个完整的意大利语包，可直接作为模板复制修改。放到本目录后重启程序即可在顶部「语言 / Language」下拉框中看到新语言，选择后立即切换全部界面文本，无需重新编译。

若语言包写错（编码、格式等），程序会安全忽略它，不会影响启动。
